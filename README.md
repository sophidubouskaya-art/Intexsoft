# Вариант 9: Игровой рейтинг

**Студент:** Дубовская С.И.

## Постановка задачи

Игрок: ник и очки. Операции:
- добавить/обновить игрока;
- топ-K по очкам;
- поиск по нику;
- среднее число очков;
- игроки с очками ≥ порога.

## Структура проекта

- `struct.py` — реализация в структурном стиле.
- `oop.py` — реализация в ООП-стиле.
